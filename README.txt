ℕ𝕩-editor — محرر صور كامل يعمل بدون إنترنت (نسخة 2.8)
Developed by Ahmed Nx
=====================================================

طريقة التشغيل
-------------
1) افتح الملف index.html في المتصفح (كروم/سفاري/إيدج). لا يحتاج إنترنت ولا تثبيت.
2) لتثبيته كتطبيق على الموبايل: ضعه على أي استضافة (https) أو افتحه من خادم محلي،
   ثم «إضافة إلى الشاشة الرئيسية». الملفات sw.js و manifest.webmanifest و icon.svg
   هي المسؤولة عن العمل بدون اتصال والتثبيت — اتركها بجانب index.html.

محتويات الملف المضغوط
---------------------
index.html                  التطبيق كله (ملف واحد)
sw.js                       العمل بدون إنترنت (الكاش)
manifest.webmanifest        بيانات التثبيت
icon.svg                    الأيقونة
README.txt                  هذا الملف
tests/suite.js              اختبارات وظيفية آلية (54 فحصاً)
tests/visual.js             اختبار لقطات الشاشة (مقارنة بصرية)
tests/baseline/             اللقطات المرجعية لاختبار الشاشات
tests/release.sh            يشغّل كل الاختبارات ثم يبني الـ zip فقط إذا نجحت كلها
tests/DEVICE_CHECKLIST.md   قائمة تجربة على جهاز لمس حقيقي (يدوية)

تشغيل الاختبارات (اختياري — للمطوّر)
-----------------------------------
المطلوب: Node.js + حزمة playwright + متصفح chromium.
   NODE_PATH=$(npm root -g) node tests/suite.js
   NODE_PATH=$(npm root -g) node tests/visual.js            # مقارنة بالمرجع
   NODE_PATH=$(npm root -g) node tests/visual.js --update   # بعد تغيير مقصود في الشكل
   bash tests/release.sh                                    # الكل + بناء الـ zip

حدود يجب معرفتها
-----------------
- لم يُجرَّب على جهاز لمس حقيقي (الاختبارات تحاكي اللمس فقط) — استخدم DEVICE_CHECKLIST.md.
- مسح QR بالكاميرا يعتمد على BarcodeDetector (متاح في كروم أندرويد غالباً، وقد لا يتوفر في سفاري):
  إن لم يتوفر استخدم «استيراد» والصق الكود أو الرابط.
- النص يبقى قابلاً للتعديل بعد القص والتصغير والتدوير؛ ويتحول لصورة عند القلب (Flip) أو الدمج.
- إزالة الخلفية وتحسين الحافة ليسا بدقة الذكاء الاصطناعي (تحليل ألوان وحواف فقط).
- «تحسين الحافة» الدقيق يحتاج الأصل المحفوظ في نفس الجلسة (يضيع بعد التراجع عن إزالة الخلفية).
